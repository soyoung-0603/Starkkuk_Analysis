
# 모바일 런타임 독립 실습

2026-11-25 KST Windows, Node.js **26.13.1**, Chrome/Chromium **158.0.8127.88**로 검증했다. 가상 객체와 직접 만든 텍스트만 쓰며 별꾹·외부 API·라이브러리와 통신하는 코드가 없다. 몰아서 실행하는 Node 테스트와 브라우저 통합 검증을 분리했다.

## 실행

프로젝트 루트에서 실행한다.

```powershell
node --test Learning/Labs/10_Mobile_Runtime/runtime.test.mjs
node Learning/Labs/10_Mobile_Runtime/browser.test.mjs 'C:/Program Files/Google/Chrome/Application/chrome.exe'
```

브라우저 테스트에는 기존 Chrome과 로컬 루프백 접근이 필요하다. 테스트가 임시 프로필과 임의 포트의 127.0.0.1 서버를 열고, 테스트 후 닫는다. 별도 패키지 설치가 없다. 브라우저를 직접 보려면 아래 서버를 실행하고 Chrome에서 `http://127.0.0.1:47261/`를 연다. 종료하려면 서버를 실행한 터미널에서 Ctrl+C를 누른다.

```powershell
node Learning/Labs/10_Mobile_Runtime/serve.mjs
```

## 정상·오류·경합 결과

| 예제 | 명령 | 예상 결과 | 실제 결과 |
|---|---|---|---|
| 최신 응답 선택 | Node 테스트 | B를 표시한 뒤 늦은 A가 도착해도 B만 반영된다. A의 요청 신호는 이미 취소됐다. | 통과. |
| 요청 취소와 화면 이동 | Node 테스트 | 닫힌 화면에 응답이 반영되지 않는다. 현재 화면의 오류는 전달한다. | 통과. |
| 로컬 버전과 저장 예외 | Node 테스트 | v1→v2 변환 성공, 깨진 JSON·미지원 버전에서 기본값, 용량 오류 때 검증된 메모리 값 유지. | 통과. |
| 일시 장애·백오프·취소 | Node 테스트 | 일시 장애에서 50·100ms 간격 모의 대기 후 복구, 영구 오류·대기 취소에서 반복 중단. | 두 테스트 통과. |
| 탭 가시성 | Node 테스트 | 모의 DOM EventTarget에서 active → paused → active, 동일 상태 중복 없음, 구독 종료 뒤 무반응. | 통과. 실제 브라우저 탭 숨김 전환은 테스트하지 않았다. |
| 비동기 모델 수명 | Node 테스트 | 두 모델이 역순으로 준비되면 낡은 모델을 해제한다. 닫기에서 현재 모델을 해제하고 읽기 실패 시 기본형 상태를 그린다. | 두 테스트 통과. 모델은 해제 횟수를 세는 모의 객체로 Three.js와 GPU는 사용하지 않았다. |
| 캐시 전략과 오류 | Node 테스트 | 캐시 적중 시 반복 요청 없이 반환, HTTP 503과 오프라인 미스는 저장하지 않는다. | 두 테스트 통과. |
| 실제 Chrome의 SW | 브라우저 테스트 | 워커 등록·현재 페이지 제어, 첫 가상 파일 응답의 Cache Storage 기록, 다음 요청의 동일 응답 재사용. 서버 응답은 매 요청마다 번호가 달라지고 HTTP `no-store`로 제공된다. | **통과.** Chrome에서 PASS 출력과 종료 코드 0. |

Node 실측 합계 **10개 통과, 0개 실패**. 초기 테스트 작성 시에는 구현 모듈 부재가 확인됐다. REA로 시도한 브라우저 실습 검증은 해당 호스트가 127.0.0.1에 연결하지 못해 실패했고, 첫 헤드리스 DOM 덤프에서도 JS 검증 완료를 확인하지 못했다. 이후 Chrome DevTools Protocol로 로컬 결과를 기다리는 통합 테스트를 실행해 위 동작을 확인했다. 브라우저에서 네트워크를 실제 차단한 시험, 설치형 앱, 모바일 회전, GPU/Three.js 검증은 범위에 포함하지 않았다.

서비스 워커의 예제는 직접 만든 `/fixture.txt` 한 요청에 cache-first를 적용한다. 별꾹 서비스 워커의 시작 페이지 네트워크 시도 방식은 [캐시 보고서](../../../Systems/Loading_Caching_Performance.md)에 있다.
